# Contract: 回転記号の読み方

サイトの `js/megaminx-state.js` の `parseAlg`・`canonicalAlg`・`simplifyAlg` と同じに読む。
境目の例は、サイトから書き出した正解データ（`test/golden/notation.json`）で確かめる。

## 読む前の置き換え

1. `’` `‘` `′` `` ` `` `´` → `'`
2. `（` → `(`、`）` → `)`
3. 空白（全角の空白を含む）・`,`・`、` の続きを、半角の空白 1 つに

エラーの位置は、置き換えたあとの文字列の位置（置き換えで文字数が変わるのは 3 だけ）。
ずれないよう、エラーの位置は元の文字列の位置に戻して出す。

## 文法

```text
手順   := 項目*                       （項目の間の空白はいくつでもよい）
項目   := 記号 回数 | "(" 手順 ")" 回数
記号   := DFR | DFL | DBR | DBL | BR | BL | DR | DL | U | F | R | L | B | D | Y
          （大文字・小文字を区別しない。長いものから先に試す。DFR → DR、DFL → DL、Y → y）
回数   := 数字* "'"? 数字*            （' の前と後の両方に数字があるとエラー。数字が無ければ 1）
```

- 記号と回数の間に空白を入れてはいけない（`R 2` は `R` と、読めない記号 `2` になる）
- 面の回転：回数 n、`'` があれば −n。時計回り 72° 単位で `((n mod 5) + 5) mod 5` 回
- 括弧：中身を n 回くり返し、`'` があれば全体を逆にする。入れ子にできる。空の括弧 `()` は何もしない
- `y`：全体を U 面の軸で回す（U と同じ向き）

## エラー

| 入力 | 結果 |
|---|---|
| 記号として読めない文字で始まる | `Invalid move: "<そこから次の空白まで>"` |
| `R2'3` のように ' の前後に数字 | `Invalid move: "R2'3"` |
| 手順の終わりで括弧が閉じていない | `Missing closing parenthesis` |
| 開いていない `)` | `Unmatched ")"` |

（ライブラリではこれに位置を足す。`api.md` のエラーの表）

## 道具

- `canonicalAlg(alg)`：読む前の置き換えをして、記号を正しい表記（`BR`・`DR`・`y` など）に書き直す。
  空白・括弧・回数はそのまま。例：`r u bR' Y` → `R U BR' y`。読めない手順は `SyntaxError`
  （サイトの `canonicalAlg` は読めるかどうかを確かめずに置き換えだけするが、それらしい文字列を黙って返さないよう
  ライブラリでは確かめる。原則 VI。読める手順の結果はサイトと同じ）
- `simplifyAlg(alg)`：サイトの `simplifyAlg` の `alg` と同じ文字列を返す
  - 同じ深さで続けて並んだ同じ面（`y` も）を足し合わせる（`R R` → `R2`、`R2 R` → `R2'`）。合計 0 回は消す。
    消えたあとに並んだ同じ面もまとめる（`R U U' R'` → 空）
  - 括弧はまたがない。中身が空になった括弧は回数ごと消す
  - まとめなかった記号は書いたまま（`R3` だけなら `R3` のまま）。空白は 1 つにそろえる
  - 書き方：1 回 `X`、2 回 `X2`、3 回 `X2'`、4 回 `X'`
- `invertAlg(alg)`：逆の手順（サイトには文字列を返す関数が無いので、新しく決める）
  - 項目の順を逆にし、記号は回数を逆にして上の書き方で書く（`R` → `R'`、`R2` → `R2'`、`R3` → `R2`）。
    0 回の記号（`R5`）は書かない
  - 括弧は中身を逆にし、後ろの回数・`'` は書いたまま残す（`(A)n` の逆は `(A⁻¹)n`、`(A)n'` の逆は `(A⁻¹)n'`）。
    中身が空になった括弧は書かない
  - 記号は正しい表記で、空白は 1 つ。例：`R U (R' F)2 BR'` → `BR (F' R)2 U' R'`
  - 読めない手順は `SyntaxError`
  - 確かめ方：どの手順でも「手順を回してから逆を回すと元に戻る」（ランダムな手順のテスト）
